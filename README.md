## 🚀 Featured Projects

A Quran verse-indexing trainer designed to help users strengthen their knowledge of verse positions and connections.

- Live on Google Play
- Built with React and Capacitor
- Node.js and Express backend
- MySQL database
- Conflict-safe cloud synchronization
- Arabic-first user experience

[View the repository](https://github.com/idrisharif88-rgb/quran-fives-react) · [Get it on Google Play](https://play.google.com/store/apps/details?id=com.shoaib.quranfives)

An offline-first, multi-tenant grocery debt tracker designed for grocery stores and their customers.

- Built with Ionic, React, TypeScript, and Capacitor
- Express and MySQL backend
- Offline-first data management
- Multi-tenant architecture
- Arabic-first interface
